Parser differentials in agent guardrails

The policy says one thing. The enforcer admits another.

"Deterministic" agent defenses like Progent let an LLM write a least-privilege policy, then enforce it in code. The promise: code can't be prompt-injected.

But the policy describes a set of allowed values, and the matcher admits a different, larger one. Pick a case below and watch a fully policy-compliant call walk straight through.

Everything on this page runs live in your browser — a faithful port of the real matcher semantics (jsonschema pattern = unanchored re.search; Progent's string branch = re.match). No server, no model.
